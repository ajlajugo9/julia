# Our Little World

A warm, interactive friendship adventure website for Julia's semester abroad.

## Pages

1. `index.html` - Home and friendship map
2. `open-when.html` - Open When letters
3. `memories.html` - Memory wall
4. `formula.html` - The Formula of You
5. `soundtrack.html` - Our Soundtrack
6. `diary.html` - Digital Diary
7. `quiz.html` - How Well Do You Know Us?
8. `puzzle.html` - Put Us Back Together
9. `countdown.html` - Until You're Home

## Run locally

Open `index.html` in a browser. The project is dependency-free and currently uses dummy data only.
